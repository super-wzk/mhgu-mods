# 极之型太刀 · MHGU 1.4

装备太刀，在装备箱的「切换风格」中选择「极之型太刀」。GU 武器编号为 7，风格编号为 3。三个狩技槽在装备箱配置。切回公会等原版风格后，GU 再次管理太刀刃色。

## 操作表

| GU 输入 | 地面动作或派生 |
| --- | --- |
| X | 拔刀。持刀时纵斩，连续按 X 接后续斩击。推摇杆按 X 可踏步起手。 |
| A | 持刀原地进入贯刺架势。可用摇杆调整刺出方向，满练气时按住 A 蓄力可出强贯刺。推摇杆按 A 可突刺。 |
| X + A | 回避斩。GU 把 R 与 X+A 识别成三键组合时，也按回避斩输入处理。气刃连段中的方向派生也读取摇杆。 |
| 短按 R | 气刃斩。在派生窗口继续按 R 接段，练气量影响招式。跑蓄斩和受身后也可长按 R 接普通气刃斩。 |
| 长按 R | 练气达到 50 后可发动气刃放出斩。有侧向输入时，从当前朝向向该侧转 22.5°。回中、正前和正后输入均保持原朝向。档位分界为 75 和 100。 |
| 持刀时同方向双推摇杆 | 持刀冲刺。冲刺中按住 R 蓄力。松开 R、摇杆回中或耐力耗尽时出斩，耐力足够时，蓄力中按 B 向前翻滚。冲刺越过台阶后，落地时保持方向且有耐力即可继续冲刺。 |
| 持刀冲刺中 X / A | 冲刺动作第 30 帧起、混合结束后，按 X 接纵斩，按 A 接突刺。纵斩从自身第 10 帧起手，第 56–65 帧刀身可命中。突刺先播放过渡动作，再从突刺片段第 20 帧开始判定。帧数均为 MHF-Z 动作帧。 |
| GU 附加肩键（默认 ZR） | 化解（いなし）。纳刀站立、行走、普通冲刺及背对怪物的逃跑冲刺均可拔刀化解。冲刺中可按住冲刺键直接点按 ZR。防御强化允许化解需要该技能的攻击。在有效帧内接住攻击后，X 派生瞬斩，A 派生反击突刺。 |
| GU 特殊攻击键 | 有斩槽时发动解放连击。斩槽 1–424、425–849 和 850 分别使用一、二、三次刀身判定，追击标记首次有效命中的大型怪物部位。 |
| B | 持刀冲刺中按 B 向前翻滚。攻击后按 B 可按摇杆方向前滚或左右侧滚。按键后摇杆回中仍保留本次方向。持刀翻滚从第 6 帧可预输入纵斩、突刺或双推冲刺，第 36 帧起执行先接受的派生。持刀被击飞时，在可受身窗口内按 B 尝试受身。 |
| Y | 收刀。GU 确认纳刀后立即清空斩槽。 |
| 台阶起跳后 X / R | 使用 GU 空中斩击或无色跳跃气刃斩，命中可积累骑乘值。 |
| 已配置的狩技键 | 樱花气刃斩保留攻击与追击，原版首次有效命中触发的升色改为加 425 斩槽，上限 850。重复命中同一段只奖励一次，刃色保持无色。练气解放圆月斩作用于上方练气槽，持续期间使用极型招式也不消耗练气。 |

太刀 HUD 在 GU 武器栏显示 FZ 的刀形斩槽和练气槽。上方红色练气条按 0–100 点从左向右填充，满练气强化期间由红转白再转红。下方刀身以黄色显示斩槽的 60 个进度帧，中间标记对应 425 点，积满 850 点时刀身闪白并持续明灭。极型启用时，GU 原生刃色固定为无色。

### 集中与杂念

| GU 装备技能 | 练气命中积蓄 | 斩槽积蓄 | 强贯刺蓄力 | 冲刺蓄力斩 |
| --- | ---: | ---: | ---: | ---: |
| 集中 | ×1.2 | ×1.2 | 100 帧 | 72 帧 |
| 无相关技能 | ×1 | ×1 | 120 帧 | 90 帧 |
| 杂念 | ×0.8 | ×0.8 | 150 帧 | 108 帧 |

帧数按 GU 的 60 Hz 动作时钟计算。极型打击使用 FZ 判定行的练气加值，再由 GU 太刀的 `2A309C` 应用技能倍率。普通 X 纵斩命中各加 28 点，两次命中共 56 点。GU 原生空中攻击和狩技沿用自己的练气加值。斩槽倍率作用于本次新增量。强贯刺仍需满练气。

刀身攻击沿用 GU 太刀模板的命中停顿。瞬斩路径将独立判定行的停顿值交给 GU `16DB68` 结算。气刃放出斩的冲击波和解放连击的追击停顿为零。极型的弹刀招式通过注册器与大剑、双剑共用判定入口。

## 构建与安装

在仓库根目录运行，使用自己的 Frontier 数据和 GU RomFS。

```sh
python3 plugins/style-registry/package.py
python3 plugins/long-sword-extreme/package.py "${MHFZ_DAT:?}" "${MHGU_ROMFS:?}"
```

将太刀的 `dist/long-sword-extreme` 安装到 MHGURecomp 的 mods 目录，在 Forge 和 style-registry 之后加载。大剑与太刀的光波判定由注册器共用钩子处理，更新时将 style-registry 和已安装的极之型武器 NRO 一起更新。

大剑与太刀共用注册器的粒子释放钩子。冲刺达到满蓄力时，太刀在刀身上闪光一次。三处持续光效沿握刀关节的局部 Z 轴分布在 100、160、220 处，闪光位于第一处并取刀身朝向。刀身关节就绪后才生成光效。出斩、回避、受击中断或卸载风格时结束。持续拖刀的地面粒子取已计算的动作根节点位置，本机和联机接收端均播放。

### 联机

房主与队员都安装同一版太刀和注册器。接收端从 GU 的 `netPlAction` 读取队员已选定的动作，按各猎人自己的播放帧提交刀身、瞬斩路径、冲击波和解放连击。房主可以使用其他武器或风格。怪物血量由 GU 结算。

`plugins/long-sword-extreme/tests/verify_multiplayer.py` 使用发布版 NRO 和 GU 1.4 的动作发送、接收及伤害函数离线回放，可用来检查队员命中归属。
