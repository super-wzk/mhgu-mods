# MHF-Z 极之型斩斧 F → MHGU 1.4

装备斩斧，在装备箱的「切换风格」选择「极之型斩斧 F」。GU 武器编号为 8，插件风格编号为 4，装备箱提供三个狩技槽。注册器将选择保存到 `savedata:/style_registry.ini` 的 `[Weapons]` 项 `8 = 4`。

光剑解锁后，有余量且剑刃展开时，瓶光跟随当前装备模型。斧与光剑的攻击、吸收防御、蓄力、放出和持刀冲刺使用 FZ 动作表。装备外观、怪物伤害结算和狩技沿用 GU。下表的帧数是动作片段里的帧号，瓶光的刷新周期按游戏时钟计算。

## 地面操作

| GU 输入 | 当前插件行为 |
| --- | --- |
| 持刀时按 X | 斧形态原地起手，再按 X 可接第二击。推摇杆按 X 会换起手。光剑形态有独立的原地和移动起手。 |
| 持刀时按 A | 斧和光剑分别使用自己的 A 起手。斧形态 X+A 上捞后接 A，持续点按 A 可消耗耐力继续连挥。光剑直接按 A 是两击起手，后续可在派生窗口再按 A 接终结。 |
| 持刀时按 X+A | 斧和光剑都有左、右、后退三种袈裟斩。当前形态的槽有余量时，朝对应方向推杆并按 X+A。摇杆回中或向前时，按当前动作允许的普通 X+A 派生处理。 |
| 收刀时按 X+A | 对应 FZ 便携机键位的三角＋圈。站定或移动时，光剑已解锁且有余量会直接出光剑拔刀斩。满槽但尚未解锁时，先播放拔刀解锁动作。 |
| GU 附加肩键（默认 ZR） | 地面进入吸收防御。有效窗口内接住怪物攻击后，斧进入状态 90，光剑进入状态 92，并积蓄光剑槽。 |
| 持刀时按 GU 特殊攻击键（踢键） | 满槽可解锁光剑。解锁后，待机可切换两种形态，连段中可接变形斩。斧吸收成功后可直接派生光剑解锁，已解锁则接展开光剑。 |
| 武器肩键（默认 R） | 按住 R 蓄力。起手后推杆最早第 40 帧可进入移动蓄力，站定按住 R 则在第 56 帧进入持续蓄力。有效蓄力时松开 R 或按 X 出乱斩，之后连续点按 X 续斩。保持 R 并按 A 可派生蓄力上挑。 |
| 袈裟斩中长按 X | 从袈裟斩片段第 18 帧起接收长按，在第 38 帧进入蓄力。蓄力片段第 40 帧前松开 X 出普通派生，从第 40 帧起松开可出强化派生。松键时推杆可改变后续招式。 |
| 持刀时同方向双推摇杆 | 斧和光剑都有持刀冲刺，分别消耗斩击槽和光剑槽。斧冲刺动画会暂时展开剑刃，受击中断后再次起跑仍按斧形态处理。首次起步经过 26 个 FZ 刻才可转向或松杆减速。越阶落地时仍推杆且原冲刺对应的槽有余量，就从原冲刺的第 90 帧继续跑，可立即转向或刹停。落地时已松杆或对应槽耗尽则结束冲刺。 |
| 冲刺或刹停时按收刀键 | 斧和光剑均可直接进入 GU 收刀动作，无须松开摇杆。 |
| 连段窗口内按 B | 耐力够本次回避时，根据当前动作和摇杆方向进入 GU 回避或风格侧移。狩技在允许的窗口交给 GU 发动。 |

## 双槽与吸收

斩击槽直接使用 GU 斩斧的原生槽。GU 进任务时初始化为 **50/100**，负责自然回复、技能倍率和上限。切换风格沿用猎人当前的斩击槽，HUD 和动作派生也直接读取该值。斧身每次有效命中向 GU 提交 6 点，无技能、集中、杂念下实际分别增加 6、7、4 点。斧招的耗槽按招式事件扣除。斧蓄力乱斩即使暂时展开剑刃，仍按 FZ 的动作表消耗斩击槽；通常的光剑乱斩消耗光剑槽。

光剑待机和普通持刀移动也会推进斩击槽的自然回复计时。通常每累计约 5 秒回 5 点，集中回 6 点，杂念回 4 点。

光剑槽由极之型单独管理，初始 **150/300**。无相关技能时，斧身命中增加 6 点，成功吸收怪物攻击增加 75 点。集中和杂念按 FZ 参数修正每次增量，分别乘 1.2 和 0.8 后取整。光剑槽耗尽时解除解锁，收招回到持刀待机后自动播放变斧动作。

**剑鬼形态**在狩技生效时保留已有的斩击槽，额外回复 25 点，并把光剑槽回满至 300 点，直接拔出光剑。集中、杂念下斩击槽分别回复 30、20 点，上限仍为 100。剑鬼期间按 GU 对应等级的计时每次消耗 3 点光剑槽，挥剑不再另外扣槽。斩击槽为零时，有余量的光剑仍可维持。光剑槽耗尽时剑鬼结束并还原斧形态。光剑打击按装备瓶种使用 GU 的剑鬼修正。

**能量累积**在狩技生效时回填斩击槽。无相关技能时，Ⅰ级回复 75 点，Ⅱ、Ⅲ级回复 100 点，上限均为 100。Ⅱ、Ⅲ级同时给予原版会心加成。剑鬼期间也能使用。发动狩技时未触及生效帧就被打断，两槽维持原值。

吸收窗口由斧的状态 89、光剑的状态 91 的事件 3 开启。无防御性能时在片段第 24 帧关闭，防御性能 +1 在第 26 帧关闭，+2 在第 28 帧关闭。FZ 的 `8181353A` 读取武器 12 的基础防御半角 90°。GU 的 `2F2BA0` 会在检查来袭方向之前排除武器 8，注册器为这个窗口补上正面判定，并保留 GU 的不可防攻击和防御强化条件。

袈裟斩接吸收防御从第 38 帧起读取 ZR 按下，提前按住要松开再按。斧形态的吸收可抢过第 18 帧起预输入的长按 X 蓄力，光剑形态会先出已排队的蓄力。片段播放结束时先收招。切入吸收时用 GU `27E608` 判断摇杆是否有方向，有效侧向输入按 FZ `81213F18` 转向 22.5°。防御方向跟随猎人切入后的朝向。

吸收成功时可提前按方向 + X+A。插件保留后仰期间的方向输入，吸收怪物攻击后从原版派生的第 10 帧接出袈裟斩。后退袈裟斩接蓄力上捞时的侧向修正为 22.5°，左右袈裟斩的对应派生为 45°，与 FZ 的 `81213F18` 一致。

可用一条短连段观察形态变化。以初始槽量持斧，用 ZR 成功吸收两次怪物攻击，待光剑槽满后按特殊攻击键，等变形动作结束再按 A。离线回放已确认这条路径能进入光剑 A 起手。另一个可观察点是进任务时的 HUD：私有贴图和两条原生槽都准备好后才显示双槽，载入期间沿用 GU 显示。

## 原版对照与验证范围

源武器是 FZ 编号 12，使用 `motion/w12.mot`。动作表有 178 个状态槽，其中 172 个含动作步骤。打包器从本地数据转换男女动作、音效、粒子、HUD 以及两组命中数据。族 106 的 81 行用于刀身，族 107 的 6 行用于放出判定。离线回放逐一进入了这 172 个状态，262 个动作步骤引用 116 个不同片段，已核对男女两套发布资源。只有满足对应输入、槽量和风格条件时，玩家才能从连段进入该状态。

| 项目 | 行为与验证范围 |
| --- | --- |

| 实机验收 | 发布包已通过离线回放。实际任务中的崩溃是否消失、各装备模型的显示效果，以及两台设备之间的联机表现，仍待实机确认。 |

动作条件和放出档位见 [program.rs](src/program.rs)，输入、状态切换和命中提交见 [battle.rs](src/battle.rs)，双槽绑定与恢复见 [hud.rs](src/hud.rs)。

## 构建、安装与离线回放

按仓库[开发指引](../../docs/development.md)准备工具链。`MHFZ_DAT` 指向 Frontier 的 `dat` 目录，`MHGU_ROMFS` 指向含 `nativeNX` 的 GU RomFS。从仓库根目录运行：

```sh
python3 plugins/style-registry/package.py
python3 plugins/switch-axe-extreme/package.py "${MHFZ_DAT:?}" "${MHGU_ROMFS:?}"
```

将 `plugins/style-registry/dist/style-registry/` 和 `plugins/switch-axe-extreme/dist/switch-axe-extreme/` 作为两个模组安装到 MHGURecomp 的 `mods/` 下，保留各自的 `romfs/nativeNX/` 层级。本版两份模组需一起更新，注册器负责队员状态与特效回收。加载顺序为 Forge、style-registry、极之型斩斧。首次安装需要整个斩斧目录，动作、音效、特效、命中形状和槽条贴图都在 NRO 之外。

离线回放需要可导入 `unicorn` 的 Python 环境、本地 `mhfz/eboot.bin.elf`、`mhgu/main.elf`、已设置的 `MHGU_ROMFS`，以及上述两份打包产物。在仓库根目录运行：

```sh
python3 plugins/switch-axe-extreme/tests/verify_port.py
python3 plugins/style-registry/tests/verify_weapon_arts.py
```

[动作回放](tests/verify_port.py)覆盖风格选择、斧 X 的预输入连段、光剑解锁及 A 起手。吸收防御从 GU 的受击结算 `2F0670` 进入，检查防御技能、来袭方向、不可防标记，以及后仰后两种形态各自的成功派生。它还会运行 [HUD 回归](tests/verify_hud.py)，用 GU 的原生模式切换代码检查贴图延迟加载、连续刷新、节点替换和退出风格后的恢复。

[原版对照与队员回放](tests/verify_branches.py)执行 FZ 的派生函数及 GU 的收发和碰撞代码，核对蓄力边界、侧向转角、放出命中计数、瓶特效以及队员的伤害归属。

[地面输入回放](tests/verify_stance.py)按游戏顺序执行公共按键解析、斩斧按键映射、原版待机表的对应指令行和风格控制器。覆盖双形态的 X、推杆 X、A、X+A、肩键蓄力与吸收、B 翻滚和长按 X 派生。特殊攻击键覆盖光剑未满时保持待机、满槽解锁、连段预输入变形斩和吸收后的两种派生。

[首次拔刀回放](tests/verify_draw_preload.py)覆盖四种极之型的统一预读入口。斩斧在任务初始化时预读当前模型的拔刀动作库、两套起手音效和粒子表。首次播放再绑定动作库，原有动作槽和起手音效帧照常使用。

[连挥与方向回放](tests/verify_chains.py)执行 FZ 的方向选择函数和 GU 的按键映射，覆盖两种形态袈裟斩的角度边界、全部六个蓄力后续、摇杆死区和 B 回避。按安装包的 LMT 回卷帧检查斧连挥和两种形态的蓄力乱斩是否能连续产生至少七次刀身判定、停按后是否收招，以及原地、移动蓄力和上挑派生。

[瓶光回放](tests/verify_phial.py)执行 FZ 的武器更新函数并检查 GU 发布包提交的粒子，覆盖六种 GU 瓶、武器挂点、三档放出、实体瓶和队员中途加入。[地形与狩技回放](tests/verify_routes.py)检查冲刺起步、刹车、收刀、侧移落崖、上台阶续跑及 GU 狩技路由。

[挥剑跟随回放](tests/verify_phial_follow.py)在瓶光出现后移动武器节点，再将武器转过 90°，从 GU 的模型绘制入口检查四组瓶光共 28 层的位置和各组剑身光层的朝向。
