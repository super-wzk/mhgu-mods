# MHF-Z 极之型铳枪 → MHGU 1.4

回避距离 UP 对专用跳步生效。排热跳步会在动作前段按方向获得额外位移。

在装备箱装备铳枪后选择「极之型铳枪」。FZ 与 GU 的武器编号都是 `9`，自定义风格编号为 `15`。启用时停用原版热度累计，原生热度槽用于显示点火计时。普通炮弹、装填、龙击炮冷却和三格狩技沿用 GU 接口。切回原版风格后恢复 GU 热度显示和累计。依赖同次构建的 `mhgu-sdk.nro`。

持刀冲刺和刹停时可发动已蓄满的狩技。橙槽归零时刀焰立即收回，此后发射的炮弹和全弹发射按普通状态结算。

| 场景 | 输入 |
| --- | --- |
| 持刀站立 | X 突刺，推摇杆加 X 接踏步突刺，X+A 上挑，A 炮击。 |
| 防御 | R 进入 GU 防御，防御中 X 接防御突刺，R+A 装填。 |
| 炮击后 | 在派生窗口按 R+A 快速装填一发。部分上挑或叩击后按 A 全弹发射。 |
| 龙击炮 | R+X+A 起手。在准备阶段按 A 改为追加装填路线，随后继续按 A 装弹。 |
| 点火 | 拔刀站立时按 GU 特殊攻击键（收刀时的踢键）。部分近战招式也可在派生窗口按此键点火。完成后启用蓄炮、连射派生及近战斩味消耗豁免。 |
| 持刀冲刺 | 同方向推、松、再推摇杆。冲刺中按 X、X+A 或 A 接各自的攻击，冲刺中按 Y 收刀。冲刺或刹停时也可发动已就绪的狩技。 |
| 受身 | 持刀被击飞后临近落地时按 B，耐力足够时可随击飞方向受身。 |

`mhfdat.bin` 的 `0x614` 下，武器 9 有 82 个状态槽。71 个由动作表描述，10 个龙击炮相关槽的动作来自 Vita `81206EFE`、`81206C9A`、`812031BA` 和 `8120300A`。状态 8 没有动作记录，也没有查到极之型的可达入口。刀身使用 FZ SDT 的动作值及时间窗、GU 铳枪的装备碰撞模板。普通炮击、蓄炮和龙击炮的伤害判定使用 GU 原生炮击类型。全弹发射超过 GU 单帧三个炮击请求时，会在后续更新补齐。

铳枪专属的热度、HUD 和拔刀钩子均在本插件。热度处理以当前任务猎人的装备和风格选择为条件，GU `11AA34C` 继续更新龙击炮冷却。依赖热度档位的原版狩技倍率也随热度一起停用。点火的近战免耗及动作派生已接通，GU 中的斩味档位、炮击成本和装备碰撞仍由 GU 处理。空中防御、普通跳攻和骑乘由 GU 处理。

HUD 沿用 GU `hud9_g_lance` 的外框和数字弹量。原热度槽内的色块以橙色从满到空表示点火剩余时间，再以蓝色从空到满表示点火冷却。蓝槽满时可再次点火。独立冷却的基础时长为 40 秒，以 FZ `8181EEA6` 写入的 w09 参数为准。站立和连段中的点火派生都检查该冷却。枪管发红沿用 GU `11A9C98` 到模型的原生路径，由龙击炮冷却驱动。

粒子使用 FZ `w09` 时间线和 `4027/4035/4036` 资源。支持 GU 粒子渲染公共路径 `effect/frontier_gl`，按源粒子层保留 Alpha、混合与 `FZF` 深度淡化。图集以阶梯关键帧切换。离线回放检查打包后的资源和 GU 绘制提交。

点火起手的片段 `1427` 播放两轮，每轮到第 100 帧时，FZ `81207560` 生成属性刃。主光和光晕使用 FZ `81FBE17C`、`81FBE3D4` 和 `81FBE5BC` 的位置、缩放和颜色曲线。将源基准点 `[128, 25, 201]` 换算到 GU 当前武器的刃轴，再按 `827BF144` 的属性行定位。两层通过模型的逆绑定矩阵跟随 GU `455EB8` 选定的枪管关节。主光按 FZ `8171A364` 绕枪刃轴转向镜头，光晕正对镜头。附属层使用 GU 适配网格，沿枪身发射。主光和光晕的深度淡化为 `0.01`，附属层为 `0.03`。亮度由共用渲染器统一调节，保留粒子 Alpha。

片段 `1428` 开始时，事件 16 开启加成，播放与太刀共用的 `81FC8398` 闪光，并由公共音库播放铳枪专用的 101 号点火音。加成期间，带事件 23 的突刺、上挑等招式再次发出刃光。动作音轨同时收录 Vita `8174B8BE` 的铳枪原生指令。普通炮击和蓄炮由动作音轨播放武器请求 13，空膛使用片段 `1410` 的请求 8。GU `11A9A54` 消费炮弹队列，原生 w09 炮弹的 FUP 音轨为空。斜上和垂直炮击在发射事件 17／18 提交 FZ `81FC3396` 的枪口闪光，使用共用绘制器和 `0.01` 深度淡化。

FZ `81207560` 在状态 28 满足最高档武器技能条件时把点火切到 1.5 倍速。GU 以炮术王及提供同档效果的复合技能触发，两段点火动画都应用该倍率。队友按发送者的技能结果播放。无技能和炮术师按 1 倍播放。

普通、快速及奔跑装填的退壳由 FZ 动作事件 26 触发，分别见状态 5／27、39–41 和 67。龙击炮准备阶段按 `81206EFE` 的帧点生成枪口充能。追加装填按 `812031BA`、`8120300A` 产生退壳、装入闪光及间歇蒸汽。普通及短发射在发射片段第 44 帧开始散热，过装在事件 27 触发。蒸汽在本地冷却期间跟随已拔出的枪管。联机回放根据已同步动作显示首次散热和装填反馈。弹壳用现有网格作弹道表现。水花、地面烟尘和枪口蒸汽使用 `0.03` 深度淡化，充能与装入闪光使用 `0.01`。

极型龙击炮采用边境的 40 秒基础冷却，追加装填和过装按各自的弹种与装填数修正。边境的冷却缩短参数映射到 GU 炮术技能。龙击炮的枪口闪光、准备和散热读取 GU 当前型号的炮口位置，经逆绑定变换后跟随枪管。斜上及垂直炮击各提交一组枪口闪光。对空火炮由 GU 的原生处理器发射并收招，保留其专用斜向爆光，龙击炮续段使用同样的冷却参数。

参考音库 `wi010` 的机械动作请求 3、装填请求 12 和炮击请求 13 都指向近静音占位波形，使用 `wi011` 的同编号波形。龙击炮请求 20、28 由 `wi037` 补齐音区。全弹按 Vita `81203B46` 提交请求 13，同时全弹只响一次，逐发射击每发响一次。追加装填的第一发沿用 `812031BA` 特定型号分支的请求 12，并用于 GU 各型号。原版其他型号在同一处使用角色语音。GU 普通防御、命中声和原版狩技继续沿用原生路径。

充能特效结束时提交的武器请求 30 是 `dbsT` 类型 2。用 `wi037` 的请求表回放 Vita `82031AF8`，该请求向现有声音提交释放命令 `0x10000001`。同一回放中，动作音效 35–37 走采样入口，分别请求装备音库 `Prog` 中程序 1 的键 63、64、65。PC 的 `wi000snd.abn` 和 `wi500snd.abn` 共核对 468 份去重音库，均缺这个程序。`we09.snd` 的请求表到 34，公共音库的同号请求属于程序 4。还需 Vita 的装备音库 `sound_vita/wi*.vsnd` 核对这组音区的原始波形。

## 联机回放

极之型动作通过 GU 原生动作包同步起手时的现有弹数。队友按原生弹仓容量回放普通、快速及奔跑装填，并在相同的动作事件提交炮击、蓄炮、全弹和龙击炮。追加装填后的剩余弹数随下一动作同步。炮弹沿用 GU 的命中、伤害归属及怪物扣血流程。联机双方需使用本次构建的铳枪插件和风格注册器。

## 构建与离线检查

发布整合包时使用 [ARC 打包流程](../../docs/development.md#本地输入和构建)。正式发布目录中，本武器的资源放在一个 ARC，NRO 独立，通用素材随 SDK 安装。下文的单武器打包和回放使用开发目录。

从仓库根目录运行。两项路径参数的含义见[开发指引](../../docs/development.md)。

```sh
python3 plugins/mhgu-sdk-runtime/package.py
python3 plugins/gunlance-extreme/package.py "$MHFZ_DAT" "$MHGU_ROMFS"
python3 plugins/gunlance-extreme/tests/verify_port.py
python3 plugins/mhgu-sdk-runtime/tests/verify_sns_gl_multiplayer.py
python3 plugins/mhgu-sdk-runtime/tests/verify_weapon_styles.py
```

将 `dist/gunlance-extreme` 和 SDK 的 `dist/mhgu-sdk/` 分别放入模组目录。铳枪回放需要 Unicorn、本地 GU 1.4 ELF、Vita ELF 和 `MHGU_ROMFS`。回放覆盖动作槽与资源引用、GU 原生组合键、炮弹与炮击队列、HUD 隔离、龙击炮计时、干湿地形分流、枪口挂点和粒子绘制。声音检查包含普通与蓄炮各方向、空膛、全弹、点火、装填和龙击炮的请求，并解码成品 ADPCM 检查是否含有可听信号。主光和光晕的曲线直接与 Vita ELF 对照，回放同时改变枪管和相机位置检查绘制结果。任务内的混音、画面和实际网络同步仍需实机确认。
