# 极之型磁斩锤

试制磁斩锤是用于验证 MHGU 1.4 装备注册、制造和购买的测试装备。武器类型与极之型风格的编号均为 16，具体装备编号为 `0x1001`。依赖同次构建的 [MHGU SDK 运行时](../mhgu-sdk-runtime/README.md)。

- 武器商店的购买武器或工房的武器生产，在原版类别之后翻到下一页，或从最后一个原版武器类别向下选择「磁斩锤」，再选择「试制磁斩锤」。购买价 **100z**，制造费 **0z**，材料为 **回复药 ×1**（GU 道具 9）。
- 道具箱首页打开「扩展装备箱」，使用 GU 的「更换装备」界面翻页和确认装备。买入和制造分别增加一个实例。交易成功后会播放 GU 原版音效，并可在原版确认框直接装备试制磁斩锤。原版「切换风格」页面显示该类型的极之型。按 A 确认可进入原版狩技页，从通用狩技中装备最多三个。
- 自己的公会卡片会在「武器使用情况」图表的原版栏目后显示磁斩锤及其独立使用次数。猎人生活日记会在新产生的相应任务记录中标注磁斩锤。
- Lv.1 使用验证用数值，攻击 100、会心 0%、无属性、无孔，斩味表 10、斩味等级 0。基础拔刀和连段有猎人、武器部件动画及近战判定。首次近战接触命中硬部位时，按当前形态弹刀，GU 心眼等豁免生效。磁力弹命中会标记怪物部位，磁力突进会追向标记，近距离反弹可以拉开距离。任务开始时斩味旁的磁力槽有五格，近战命中和时间经过会补充。槽旁一枚亮点表示反弹距离，两枚表示突进距离。
- 双方使用同次构建的 SDK 和磁斩锤插件时，联机接收端按动作包播放队友的动作、武器部件和音效，近战命中归属出招的队友。磁力突进的滑落姿势随 GU 周期位置包同步。磁力弹的弹道和部位标记仍待同步。磁力槽消耗及回充闪光、格挡特效、世界中的标记和弹道特效待接入。

五格磁力下方的左、右两条分别显示斩击和打击形态的磁气。命中会积累当前形态的磁气。发动后该条变为金色并显示剩余的强化时间，持续 80 秒。强化期间出招的动作值提升 10%，两种形态分别计时。强化结束后灰条显示 100 秒的冷却，冷却期间命中不累计磁气。

## 模型和图标来源

MHF-Z 的 `mhfdat.bin` 近战装备记录 16881 指向模型 6451，类别为 13。网格、骨骼和原色贴图来自 `dat/extend/wk000.abn` 的 `wk451.bin`。转换器使用 GU 材质模板生成 MRL，连同 MOD 和 TEX 写入 `arc/frontier/magnet_spike.arc`。GU 注册资源名为 `weapon\frontier\magnet_spike\wk451`。

打包时从本地 MHF-Z 的 `dat/mhf.bin` 读取第 54 号 PNG 条目（从零计数），原样取出左上角坐标为 `(192, 896)` 的 64×64 磁斩锤图标。生成的 `GUI/frontier_magnet_spike/icon.tex` 和 NRO、模型 ARC 一起安装。

磁斩锤的 FZ 武器编号为 13。打包时用 `magnet-spike-battle` 将 `motion/w13.mot` 的猎人动作、`motion/w13w.mot` 的部件动作与近战 HTS 写入同一个武器 ARC。部件动作和相应的近战挂点使用 `wk451.bin` 的骨架。控制器从打包时生成的 `magnet_spike.fmsa` 读取原版动作、形态分类和近战判定参数。[转换器命令](../../tools/mhfz2mhgu/README.md)

同一 ARC 内的音效取自 FZ `sound/we13.snd` 与 `sound/common01.snd`，重新封装为 GU 的音频资源。FZ `mhfdat.bin` 的 w13 动作音效表编入 NRO，由 GU 原版空间音频队列播放。试制模型缺少独立 `wk451.snd` 条目，型号专用音效仍待核对。

## 构建与验证

从仓库根目录运行以下命令。

```sh
python3 plugins/mhgu-sdk-runtime/package.py
python3 plugins/magnet-spike/package.py "$MHFZ_DAT" "$MHGU_ROMFS"
python3 plugins/magnet-spike/tests/verify_magnet_spike.py
python3 plugins/magnet-spike/tests/verify_battle.py
python3 tools/package_weapon_styles.py --include-magnet-spike
python3 tools/tests/verify_packed_release.py --include-magnet-spike
```

成品回放覆盖两种插件加载顺序，执行 GU 商店和工房的原版入口与交易控制器，并核对成功音效指令、立即装备、预览初始化、预览方向输入、装备数值和模型绑定。游戏内的实际音效和 3D 画面需要实机确认。安装时从整合包取出 `mhgu-sdk/` 和 `magnet-spike/`，保留各自的目录结构。

打包回归检查猎人动作组 0、2、4 与武器部件动作组 0、1、2、4 的 LMT 目录。部件动作组 1 只含 0、1、2 三个槽，供 FZ `8121E3EA` 选择收刀及两种持刀形态的常驻姿势。

战斗回放从 GU 猎人派发和原生命令解释器进入，检查两种拔刀、跨片段预输入、斩击与打击起手、B 翻滚、回退武器命令隔离及任务预读。使用成品 ARC 核对动作槽、部件采样帧和近战 HTS。以固定的部件矩阵验证双刃胶囊、重叠连击、眩晕积蓄、攻击力读取和 GU 的扣血与玩家归属，实际动作外观和命中手感待实机确认。[战斗回放](tests/verify_battle.py)

回放还核对斩味修正后肉质 0.23 的边界、首次接触消耗判定、磁力攻击第二击重新开启判定、无效命中编号、心眼豁免和两种形态的弹刀片段。切入弹刀动作时清除 GU 的全停和减速计时器。

格挡回放检查防御性能延长窗口、防御强化、攻击方向和 GU 不可防的打击类型。只有 GU 确认格挡的接触才计数，格挡成功保留当前动作且免除伤害、耐力、斩味和磁力消耗。回放覆盖斩击反击的三个状态、打击格挡突击的 X／X+A 派生，以及两种反击在队友侧的动作和命中。

音效回放检查任务预读、磁力弹发射帧和挂点，以及首次斩击格挡的两条叠播请求。队友侧在收到斩击反击动作时播放格挡音效。同一动作帧重复采样只触发一次发射音效。实机混音与双机听感待确认。

同一回放检查两种磁力弹的发射帧、镜头方向锁定、GU 受击体积的命中、标记的跟随、目标死亡及到期清除，并模拟地形遮挡、水面和暂停。磁力弹命中仅记录部位，怪物 HP 和伤害归属保持原值。

回放还检查两种形态的磁力攻击、一次性扣除、空槽拒绝和按时回充。近战回充使用 GU 结算的会心倍率，依 FZ 的顺序逐步取整后再计入磁缠强化。集中与杂念分别使本次命中回充变为 120% 与 80%。强化时预先提高交给 GU 碰撞的动作值，伤害会心由 GU 结算。回放核对两种强化动作、磁气独立积累、冷却、状态条和队友强化后的近战动作值。强化的专用特效及特殊派生待接入。

磁力突进回放在固定场景中执行 GU 的空中位移和落地入口，覆盖无标记、目标过近或过远、耐力不足、起步时序、转向、停顿、墙体、射击后预输入、斩击和打击的空中攻击及空中回避。实际地形和动作衔接的观感待实机确认。

近距离反弹回放按 GU 输入进入两种形态的后撤，核对无标记、标记失效、超距、耐力和磁力门槛。回放用成品根轨采样驱动 GU `53A5BC`，并检查后撤方向、回避时间、射击接反弹与后撤接突进的窗口。

同一回放走 SDK 在 GU `544CC8` 和 `544DB8` 安装的 HUD 更新与绘制钩子，检查九种回退武器专用布局、切回固定装备后的绘制、五格磁力的消耗与部分回充，以及标记从近距进入远距、超距、死亡或到期后的亮点变化。磁力槽复用 GU `hud0.gui` 的原生多边形和显示规则，以条格与亮点呈现 FZ 的余量与距离提示。实际位置、可见性和配色待实机确认。

联机回放经 GU `202894` 接收装备资料，再走 `1FED90` 和 `1FF308` 的动作收发入口。覆盖两名队友的独立游标、拔刀分段播放、弹刀和起飞落地、翻滚时按包更新的武器姿势、近战碰撞和伤害归属，以及原版装备记录替换后拒绝私有动作。`netPlAction::mPlAttr` 的位 22–25 保存扩展武器状态，回退类别的原版位 16–19 保留。双机位置和画面待实机确认。[联机用例](tests/verify_peer.py)

滑落回放在本地打击形态撞墙时，经 `200438` 捕获 GU 发出的原版位置包，再经 `1FFFF4` 接收并调用 GU 的位置插值。检查队友在同一动作内从 1460 切到 1461，多次收到滑落状态时保持播放进度，并拒绝同一个动作 ID 上一次启动的滑落标记。两种形态沿用各自的滑落片段 1471／1461。动作包在形态位之外携带两种强化的生效位，位置包同步同一动作内的强化到期。[联机用例](tests/verify_peer.py)
