# 极之型磁斩锤

斩、打两形态的左右及后方磁力回避受回避距离 UP 影响。

试制磁斩锤是用于验证 MHGU 1.4 装备注册、制造和购买的测试装备。武器类型与极之型风格的编号均为 16，具体装备编号为 `0x1001`。依赖同次构建的 [MHGU SDK 运行时](../mhgu-sdk-runtime/README.md)。

战斗中，队员姓名旁显示该猎人所装备的磁斩锤图标，保留队员颜色。右上角目标选择提示显示按下右摇杆。

选档模型随当前光标所指角色的装备切换。试制磁斩锤的能力值来自该实例的强化等级，匠和装饰品技能随当前配装结算。

持刀冲刺和刹停时可发动已蓄满的狩技。

- 武器商店的购买武器或工房的武器生产，在原版类别之后翻到下一页，或从最后一个原版武器类别向下选择「磁斩锤」，再选择「试制磁斩锤」。购买价 **100z**，制造费 **0z**，材料为 **回复药 ×1**（GU 道具 9）。
- 道具箱首页打开「扩展装备箱」，使用 GU 的「更换装备」界面翻页和确认装备。买入和制造分别增加一个实例。交易成功后会播放 GU 原版音效，并可在原版确认框直接装备试制磁斩锤。原版「切换风格」页面显示该类型的极之型。按 A 确认可进入原版狩技页，从通用狩技中装备最多三个。按 X 可直接查看操作指南，也可从猎人笔记选择「磁斩锤 → 极之型磁斩锤」。
- 名片封面在模型加载后显示扩展武器。双方安装对应武器时，新版刷新并交换的名片也可显示该武器。自己的公会卡片会在「武器使用情况」图表的原版栏目后显示磁斩锤及其独立使用次数。猎人生活日记会在新产生的相应任务记录中标注磁斩锤。
- 在工房首页选择「扩展装备强化」，从装备格中选择已持有的武器，查看材料和升级前后数值，再确认强化。Lv.1 到 Lv.8 每级消耗 **回复药 ×1，0z**。已买入或制造的同一把武器可直接强化。测试武器可自由选择强化进度。
- Lv.1～8 的攻击依次为 **100、110、140、170、210、240、290、320**，孔数依次为 **0、0、1、1、1、2、2、3**。全程无属性、会心 0%。基础斩味从 Lv.1 的黄斩提升至 Lv.2 绿斩、Lv.4 蓝斩和 Lv.7 白斩。Lv.2 起参照 GU 原版 w07 第 1 系列第 5～11 级的攻击、斩味与孔数。
- 在扩展装备箱进入原版装饰品、移动或出售子页面，再选择要操作的实例。试制磁斩锤 Lv.1～8 的基础卖价引用 GU w07 第 1 系列 Lv.4～11，已镶嵌珠子另按 GU 卖价结算。工房详情按同一参考行显示冠标，Lv.1～4 无冠，Lv.5～7 银冠，Lv.8 金冠。强化预览显示目标等级的冠标。Lv.3 起有插槽，Lv.6 起可装两孔珠，Lv.8 可装三孔珠。
- 本地磁界弹与部位标记由 GU 的场景粒子绘制。弹道随判定位置移动，标记贴随命中部位，目标失效或标记到期时移除。按 FZ 普通任务的规则，每位猎人只看到自己发射的部位标记。
- 斩击首次格挡时，闪光和后续火花随武器移动。打击精准防御时，身前会产生爆闪和尘土或水花，武器挂点随后闪出火花。
- 磁界脱离时，同区的队友也能看到武器挂点、标记部位和猎人身后的闪光。
- 磁缠强化生效时，武器闪光。持刀期间，当前形态按原版周期在武器上喷出火花，同区的队友也能看到。
- 双方使用同次构建的 SDK 和磁斩锤插件时，联机接收端按动作包播放队友的动作、武器部件和音效，近战命中归属出招的队友。收到斩击反击或打击精防成功动作时，接收端播放对应格挡特效。磁界接近的滑落姿势随 GU 周期位置包同步。磁界弹的发射方向和结束随 GU 位置包同步，实际命中的部位随 GU 怪物资料包同步。

组合键可以同按，也可以先按住一键，在约 67 毫秒内补齐其余按键。R+X+A 支持三键的六种顺序。自由态的单独 B、Y 在松开或组合窗口结束时分别触发 GU 翻滚和收刀。ZL+B 缺少近距标记、磁力或耐力时留在原地。连段以按键或组合完成时所在的动作帧检查 FZ 派生窗口。

按键表按 Switch 标记。Xbox 手柄使用 MHGURecomp 默认位置布局时，RB 加左侧 X 是左回避，加右侧 B 是右回避，加下方 A 是后撤，加上方 Y 是前方二连。两种形态均可从持刀自由态发动。

磁斩锤招式使用表中的物理肩键。磁力回避消耗一格磁力和耐力。消耗耐力的磁力招式与紧急着地也会缩短强走药和强走旋律的剩余时间。免耗效果仍保护这一次耐力结算。按下右摇杆（R3）使用 GU 原生目标选择，暂停菜单的「使用说明书」可查看磁斩锤按键。招式名直译自 FZ 原名。[磁界接近与脱离](https://www.youtube.com/watch?v=-aXvEzl8CrM) · [斩击形态磁力回避](https://www.youtube.com/watch?v=taCFWn4GjtM) · [打击形态磁力回避](https://www.youtube.com/watch?v=BLJoKjC9K3Q) · [防御动作](https://www.youtube.com/watch?v=HnfFUvzeDfE)

五格磁力下方的左、右图标分别显示斩击和打击形态的磁气。命中会积累当前形态的磁气。达到半槽、充满、发动强化和冷却各有原版图案与动画。强化持续 80 秒。强化期间出招的动作值提升 10%，两种形态分别计时。强化结束后图标进入 100 秒的冷却，冷却期间命中不累计磁气。

负责模拟该怪物的 GU 客户端将本地和队友的磁斩锤命中合并，按怪物出生实例累计磁缚值。每次贡献取实际动作值（含强化和会心修正），积蓄计数最多储存 32767 点。控制端通过 GU 怪物资料包发布积蓄和成功次数。同区玩家可看到达标怪物受击关节附近的周期闪光，使用原版武器时也可看到。已收到该怪物资料的客户端接手控制权后，会从最近确认的积蓄和成功次数继续累计。磁缚资格读取该出生实例的 GU 麻痹参数，初始麻痹阈值和持续时间均须为正。所有任务首次均需 **1800** 点。同一只怪物后续依次需要 3420、6498、12346、23457 点，之后保持 23457 点。磁缚计量独立于原生麻痹积蓄。

GU 移植采用 FZ 第 7 组常见的 1800 点作为首次阈值。对 `mhfemd.bin` 的 177 个怪物条目过滤种类标志、正的初始阈值和正的持续时间，每个任务数据组留下 108 项。按从 0 开始的组号，0～6、8、10、11 组的首次阈值全部为 1600。第 7 组有 107 项为 1800、1 项为 2000（种类 156）。第 9 组全部为 2000。1600 点的各组按 190% 提升耐性，106 项可提升四次，2 项可提升八次。

磁缚落空后立即翻滚、正常收招或被击飞，均保留起手形态；翻滚后的攻击按该形态派生。着地后的无伤害判定可束缚一只已积满的地面怪物。怪物暂用 GU 的地面受制动作。按 FZ 的初始时限、输入间隔和延长目标运行交互，左摇杆沿用 GU 的死区并按四个方向区间读取变化。磁缚成功后，屏幕中央显示原版磁缚槽，游标位置取决于当前束缚计时，成功延长时播放脉冲。进入磁缚交互后，本地镜头随被束缚的怪物转向并逐步拉远，终结动作进入后段时切换构图。仍可用 GU 原版镜头输入微调横向视角。达标时游标切换图案，提示等待终结窗口。束缚倒计时结束后，提示换成「按 ZR 使出磁缚终结」，游标停在槽尾。终结时猎人转向目标。GU 结算武器挂点的斩击后，命中的地面怪物若可倒地，会进入该怪物自己的倒地动作，命中被束缚的目标时结束束缚计时。终结只结算出招者束缚的那只怪物。打击形态的派生在失败或终结后播放对应的恢复动作。一次磁缚持续超过 30 个 FZ 更新刻时，消耗积蓄并将该怪物下次的阈值提高到本次的 190%，最多提高四次。束缚期间，怪物关节与其上方分别出现原版脉冲和光效。出招者确认磁缚时听到音效并看到身前闪光，随后从身前持续发出朝向目标关节的脉冲。交互期间的周期音效和身前解除闪光也沿用原版资源。束缚解除时停止仍在播放的受缚粒子，同区存活怪物播放一次解除闪光。联机时双方需使用同版 SDK。怪物动作和受制计时通过 GU 原版怪物动作包同步。同区客户端根据收到的受制动作播放原版受缚和解除粒子。当出招者和怪物由不同客户端控制时，出招端只向一个重叠且已达阈值的目标提出申请。怪物控制端核对猎人的着地动作、距离、出生实例、受击体积和当前积蓄，再发送确认。猎人收到确认及受制动作后才进入交互。中断、离场或超时会撤销申请或释放束缚。同区怪物控制端在队友动作第 164 帧创建终结碰撞，出招端和其他观察端在第 184 帧创建。每端只提交一次，扣血和倒地由 GU 原生流程结算。受制期间转移控制权时，已收到该怪物活动束缚记录的同区客户端接续原有受制动作和计时。出招者继续当前交互，释放和耐性结算随控制权转移。[原版开发团队操作演示](https://www.youtube.com/watch?v=orMv3sxAzAs)

## 模型和图标来源

MHF-Z 的 `mhfdat.bin` 近战装备记录 16881 指向模型 6451，类别为 13。网格、骨骼和原色贴图来自 `dat/extend/wk000.abn` 的 `wk451.bin`。转换器使用 GU 材质模板生成 MRL，连同 MOD 和 TEX 写入 `arc/frontier/magnet_spike.arc`。模型保留 FMOD 的原始 UV，收刀后从猎人背后看，两侧下端的装置为左蓝右红。GU 注册资源名为 `weapon\frontier\magnet_spike\wk451`。

打包时从本地 MHF-Z 的 `dat/mhf.bin` 读取第 54 号 PNG 条目（从零计数），原样取出左上角坐标为 `(192, 896)` 的 64×64 磁斩锤图标。生成的 `GUI/frontier_magnet_spike/icon.tex` 和 NRO、模型 ARC 一起安装。

磁斩锤的 FZ 武器编号为 13。打包时用 `magnet-spike-battle` 将 `motion/w13.mot` 的猎人动作、`motion/w13w.mot` 的部件动作与近战 HTS 写入同一个武器 ARC。部件动作和相应的近战挂点使用 `wk451.bin` 的骨架。控制器从打包时生成的 `magnet_spike.fmsa` 读取原版动作、形态分类和近战判定参数。[转换器命令](../../tools/mhfz2mhgu/README.md)

离线验收遍历 165 个状态槽，逐项核对 244 行动作步骤、1,784 行派生和 598 行事件与原始数据的内容。`tests/verify_battle.py` 通过 GU 的输入、动作、碰撞和 HUD 入口回放，并直接执行 Vita 的蓄力与磁力自然恢复函数。`tests/verify_fx.py` 逐层加载成品 ARC 的 1,347 个粒子层，检查 GU 的绘制输出。

试制武器模型 6451 在原版型号表中选用音效模型 6416，武器声来自 `extend/wk000snd.abn` 中的 `wk416.snd`。另外打包 `we13.snd`、`common01.snd` 及男女默认猎人语音波形。GU 的地面和防具音效入口按现场材质及穿戴装备处理脚步和护甲声。离线回放分别检查 163 个片段内的 1,313 行音效和 167 个片段内的 962 行有效动作粒子，覆盖随机分支、混合期和重复采样。

原版还在动作表之外按状态、帧、磁缠和标记位置发出反馈。斩形态 GP 反击第 32 帧在身前叠放两层音效，同时生成判定族 121 第 5 至 7 行中的一条。独立判定从前方 100 处起步，每个 FZ 周期向前移动 40，动作值按成功格挡次数取 80／95／120。磁缠强袭后续片段 1035 在第 38 帧生成第 10 行的连续冲击。接近目标时的腕部闪光和声音共用一次触发标志。磁缚连打达标后播放怪物提示，终结另在第 114、184 帧发声。站立、行走和冲刺收刀按照两种形态选择独立片段和回背帧。

磁界弹和部位标记使用 FZ `effect.bin` 的 4037 号特效组第 11、14 项，两种格挡使用同组第 21、22、70、71 项及 4035／4036 组第 2 项。磁界脱离使用 4037 组第 1、77、78 项。磁缠强化使用 4038 组第 16 项及 4037 组第 85–88 项。强化磁冲击使用 4038 组第 45–48 项及本地的 4037 组第 84 项。普通磁冲击使用 4038 组第 50–52 项及本地的 4037 组第 83 项。转换后的模型、贴图、EFL 与 PEL 存入同一 ARC。打包脚本从 GU `arc/player/quest/w00.arc` 读取粒子定义和材质模板。磁缚起手片段 1421 和终结片段 1488 从 FZ 动作特效表读取发射帧、偏移和挂点，转换原粒子。终结蓄势火花随武器和手部关节播放，第 184 帧在猎人前方发出冲击。
