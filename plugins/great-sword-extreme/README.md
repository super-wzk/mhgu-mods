# MHF-Z 极之型大剑 → MHGU 1.4

极之型大剑是 [style-registry](../style-registry/README.md) 的风格插件，编号 **1**。装备大剑后，在装备箱原版「切换风格」列表中选择「极之型大剑」并确认。男女猎人均可使用 Frontier 的大剑动作和 GU 的跳劈。

极之型的独立招式编号登记在 GU 武器动作组 `16:0x8000..0x80ff`。GU 派发动作、解析指令并播放已登记的动作请求。插件按 Frontier 的时间表判断蓄力层数、派生优先级和预输入窗口，已选中的派生和狩技交给 GU 的命令表执行。奔跑拔刀接收 GU 已接受的原生请求。点按在十帧拔刀分流窗口转入普通拔刀斩，持续输入则继续蓄力。公共移动、回避、防御碰撞、受击、装备和命中音效由 GU 提供。

| 持刀操作（GU 键位） | 游戏中的行为 |
| --- | --- |
| X | 纵斩；长按蓄力，松手出刀。纵斩最高三段，释放时推左或右可修正出刀方向 22.5°。 |
| A | 横扫。连段窗口内可以配合方向输入派生；部分窗口只有这一剑击中怪物才会延长。 |
| 空中 X | GU 跳劈。落地派生窗口内，X 接边境纵斩的终结攻击，A 接边境横扫，摇杆同方向双推接持刀冲刺。横扫保留后续连段。 |
| X+A | 收刀站立或移动时直接拔刀上挑，持刀时直接上挑。点按为普通上挑，长按可至四段。四段窗口内松手打四段，按到超时则降为二段。出刀后重新按 X+A 可接前砍，普通上挑接收第 68–145 动作帧，蓄力上挑接收第 76–153 动作帧。 |
| 摇杆往同方向连推两次，中间回中 | 持刀冲刺，消耗耐力。X 接冲刺斩，X+A 接蓄力上挑。冲刺中可攀爬或翻滚跳下台阶，恢复时保持方向即可继续冲刺。停止推动时减速，Y 收刀。 |
| 防御键（通常为 R） | 精准防御。实际挡住攻击后，X 接下劈，A 接横扫，两者在派生执行时可朝摇杆方向出招。没有挡到攻击不能派生；只有挡住怪物才能蓄积辉烈剑。收刀时的 GU 拔刀防御指令保留为防御，不转成上挑。 |
| 成功防御怪物三次后按特殊攻击键（踢键） | 从防御成功动作或持刀待机发动辉烈剑，消耗积蓄。连续判定有独立形状和命中编号，全部光波判定均不消耗斩味。 |
| 蓄力或攻击中点按 ZR（默认） | 在该招允许抵抗硬直的窗口发动不动，消耗一次回避所需耐力；仍会受伤。原版 FZ 不动为 R2，防御为 R1；在 GU 中分别对应 ZR 与 R，交换肩键类型时一起交换。无需按踢键。 |
| B | 在连段允许时回避。防御动作第 56 帧起可按 B 派生翻滚。普通上挑从源动作第 68 帧、蓄力上挑从第 76 帧可侧滚。按 B 时确定方向，随后摇杆回中仍保留这次方向。持刀翻滚第 30 帧起可预输入 X 或 X+A，第 44 帧起由 GU 执行。GU 解析组合键期间会暂缓选择 X 的纵斩派生，识别出 X+A 后可接四蓄上挑。翻滚下台阶后，落地恢复时同方向双推摇杆可接持刀冲刺。持刀被击飞并落地后，可消耗耐力受身。 |
| Y | 持刀待机、行走或冲刺时普通收刀。极之型停用勇气槽和勇气纳刀。 |
| GU 原生狩技指令 | 可在装备箱配置三个狩技。狩技槽由 GU 充能和显示，极之型按各招式的狩技窗口开放发动。 |

将 `MHFZ_DAT` 设为 FZ 的 `dat` 目录，`MHGU_ROMFS` 设为包含 `nativeNX` 的 GU RomFS 根目录。从仓库根目录运行：

```sh
python3 plugins/style-registry/package.py
export MHGU_ROMFS="${MHGU_ROMFS:?请指定 GU RomFS 根目录}"
python3 plugins/great-sword-extreme/package.py "${MHFZ_DAT:?请指定 FZ 的 dat 目录}"
```

将两个插件各自的 `dist/<插件名>` 安装到 mods 目录，并让 `style-registry` 先于极型大剑初始化。若顺序相反，本次启动继续使用原版风格。菜单选择立即生效，由注册器写入 Forge 的 `savedata:/style_registry.ini`；要切回原版，在同一页确认任一原版风格即可。

打包后运行 `tests/verify_assets.py`、`tests/verify_style.py`、`tests/verify_menu.py`，需要 Unicorn、本机 Vita/GU ELF 和 GU 的大剑资源包。提取的动作和指令表在 `target/assets`。安装包将男女各三个 LMT 放在独立的 `player/mot/frontier_gs` 路径，保留组内槽号与空槽；不覆盖 GU 的 `w00.arc`。

- **源武器。** Vita 日文武器名表 `82CB0558` 的第 0 项是「大剣」，第 3 项是「ランス」。原版载入器以同一武器编号查 `8258A2EC` 和 `82BB30E8`：大剑取 `motion/w00.mot`，长枪取 `motion/w03.mot`。极之型的风格编号 3 与武器编号无关。
- **动作。** w00 的上下半身按 0/1、2/3、4/5 三组配对，分别得到 11、3、67 个全身片段。程序保存武器 0 的 74 个源状态；其中有其他 Frontier 风格的分支和原生代码处理的空表项，不能按 74 个独立可操作招式计算。武器挂点按 Frontier `819070E2` 的时序写入 GU 动作事件：拔刀斩先从背部到右手、再交左手；拔刀上挑起手用右手；防御与成功格挡分别在第 52、106 帧换回左手。进入动作的混合期间保留原版指定的挂点。GU 原版负责装备箱、挂点变换、被击飞的物理过程和普通回避。
- **判定。** 纵斩与上挑按各自的蓄力行取动作值。动作值在 GU 构造碰撞时传入，兽魂附身、装备修正和命中结算走原生武器路径。辉烈剑使用 FZ 特效组 108、第 8 项的独立胶囊，动作值 27。挥剑片段第 84 动作帧生成首波，此后每 0.2 秒一波。完整释放共 17 波，无技能时全中合计动作值 459。每波光效和命中胶囊固定在同一个世界坐标，发射点位于猎人朝向前方 200 单位。冲击波的攻击者命中停顿为零，命中怪物时猎人以原速收招。
- **声音。** 挥刀跟随实际播放的 Frontier 动作帧；普通铁大剑的音色取自 FZ 装备音库。不动、蓄力、成功格挡和蓄积完成由招式事件触发。弹刀和命中继续用 GU 公共资源，由原版碰撞结果决定，不在动作时间线上另播一次。
- **精准防御。** FZ `8174277A` 允许极之型大剑在精准防御窗口内以零耐力挡住普通可防攻击。移植沿用这一规则，攻击可防性和防御强化仍由 GU 判定。FZ `81744DA0` 在碰撞确认时给予 4 个逻辑帧保护，成功动作的事件再给予 7 个逻辑帧（约 0.233 秒）。GU 公共无敌计时器按实际帧间隔递减。精准防御成功时斩味消耗为零，包括高威力攻击和通过防御强化挡下的攻击。以上已通过定向原生函数检查，实机表现仍需确认。
- **弹刀。** 极型按 FZ `811D84FE` 的状态和打击事件判断。允许反弹的刀身首次命中斩味修正后肉质低于 0.23 的部位时进入状态 3，播放片段 1404。横扫和精防下劈可弹刀，蓄力释放和辉烈剑光波豁免。反弹中第 2 帧起可预输入攻击键，第 18 帧起可接状态 16，第 30 帧关闭窗口。帧数按 GU 动作时钟计算。
- **精防下劈。** 精防成功接 X 时，第 86 动作帧提交一次原版近战判定（SDT 247，动作值 200），持续 10 个 30 Hz 逻辑帧。GU 按猎人根节点展开形状 39。标准剑长的胶囊半径为 200，中心线在正前方 200 单位，高度为 50 至 250。原版片段 1476 在第 90 帧播放 4022 组第 10 和 16 项，第 92 帧播放第 6 项，第 100、108 帧各播放一次第 5 项。每次发射取当时猎人的位置和朝向。
- **特效。** 打包时从 Frontier 转换模型、贴图和曲线，生成 GU 原生 EFL/PEL 资源。插件发出开始、升段和结束请求，GU 负责生成粒子、求值曲线、更新朝向和挂点，以及结束播放。蓄力光环常驻四层，升段时另生成两层闪光。普通三段和上挑第四段均有反馈。上挑释放、不动、辉烈剑和满蓄积也使用原生粒子系统。
- **蓄力与地面反馈。** 纵斩从事件 30 起以半速播放蓄力动画，与 FZ `811D84FE` 一致。升段仍以蓄力刻计时，事件 30 计入第一刻，无技能、集中、杂念的第一段分别在累计 40、32、48 个 FZ 刻时到达。蓄力光环及升段闪光按层记录 GU 的接收结果，缺失的层在本次蓄力或升段期间重试。上挑从骨盆挂点发出身体光效，地面碎屑和溅水使用发射位置处的 GU 地形查询。三蓄纵斩使用标准大剑长度计算刀身上的五个溅水采样点。
- **粒子材质。** 模型采用 GU `cm153_000` 的 `IANonSkinBC` 顶点布局，材质保留配套的 `FEmissionConstantEflEmu`。实机蓄力的绘制包通过 `CBPrimEflEmu` 读取 Frontier 粒子颜色。布局或材质请求的组合在 GU 中缺少预编译着色器时，引擎可能改用 `CBTest.fDummyColor` 绘制白色贴图。图集保留 Frontier 的 UV，关闭跨图块的自动 mipmap，混合方式取自各层 EFL。蓄力光环和升段闪光的 m66 层直接使用 t3 图集的原始透明度，按 FZ 的源 Alpha 加法混合绘制。打包从 `MHGU_ROMFS` 指定的目录读取 GU 资源。`verify_native_fx.py` 检查原生曲线，`verify_native_material.py` 检查材质、顶点布局和绘制参数。
- **验证范围。** 离线运行原版 FZ 的动作、蓄力与判定函数，也用打包后的插件回放 GU 的输入、持刀挂点、受身、格挡、命中写回和多段判定。联机时，接收端按队员自己的动作帧播放大剑，以发送方的蓄力档位构造斩击。房主可使用其他武器。双方需安装配套注册器和武器资源。两名队员的动作、命中归属及怪物扣血已通过 GU 原生收发回放，双机任务仍待验收。
