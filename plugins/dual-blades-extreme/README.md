# MHF-Z 极之型双剑 → MHGU 1.4

装备双剑后，在装备箱的「切换风格」选择「极之型双剑」。风格编号为 2，使用 GU 武器编号 11。注册器按武器分别保存风格和显示名称，双剑可配置三个原生狩技。狩技的蓄积、显示和发动继续走 GU。

任务中，双剑槽上方的四枚短刃从左到右点亮，每枚对应一层生效中的刃打加成。下方的火焰槽在真／极鬼人解放中随时间和命中蓄积，真鬼人转极鬼人时继承进度。满槽后火焰变亮，后续斩击获得强化。退出解放时火焰槽清零。

| GU 输入 | 极之型动作 |
| --- | --- |
| X | 斩下与后续连段。持刀冲刺中按 X 可接上捞斩。 |
| A | 回旋斩。极鬼人解放中改为上升斩。 |
| 地面连段中按 X+A | 扫斩及其派生，具体招式随前置动作与鬼人阶段变化。 |
| GU 鬼人化键，默认 R | 持刀按下进入鬼人化，继续按住依次进入真鬼人、极鬼人。启动中松手可停在普通或真鬼人，进入极鬼人后松手保留状态。再次短按解除。 |
| B | 普通回避，或按鬼人阶段与方向发动鬼人回避。 |
| GU 特殊攻击键 | 使用锋利度恢复招式。可派生的阶段和窗口跟随动作表。 |
| 持刀时同方向双推摇杆 | 消耗耐力并冲刺。冲刺可衔接攻击、回避和收刀。 |
| 持刀冲刺中按 A | 耐力足够即可在平地发动空舞连斩，最多 5 段。空中命中怪物后，约半秒内再次按 A 派生下劈终结。这两条派生的骑乘积蓄为零。 |
| 跳下台阶等普通滞空时按 X | 短距离向前下劈，直接发动空舞终结，最多 2 段。命中可累积 GU 骑乘值。 |

普通斩击按 FZ `811EF80C` 的状态判断弹刀。左右手共用本次打击的首次接触，斩味修正后肉质低于 0.23 时进入状态 11，播放片段 1408。刃打效果生效期间与空舞连斩、空舞终结豁免。反弹中第 14 帧起可预输入攻击键，第 32 帧起可接状态 17，第 40 帧关闭窗口。帧数按 GU 动作时钟计算。

## 打包

从仓库根目录运行。将 `MHFZ_DAT` 指向 Frontier 的 `dat` 目录，将 `MHGU_ROMFS` 指向包含 `nativeNX` 的 GU RomFS。

```sh
python3 plugins/style-registry/package.py
python3 plugins/dual-blades-extreme/package.py "${MHFZ_DAT:?}" "${MHGU_ROMFS:?}"
```

把两个插件的 `dist` 内对应目录装到 MHGURecomp 的 mods 目录。初始化顺序为 Forge、style-registry、极之型插件。双剑的刀轨通过注册器提交给 GU 粒子绘制入口。

男女动作、挥刀音效、磨刀粒子、鬼人刀身光效和极鬼人闪避粒子由本地 Frontier 数据生成，使用独立的 `frontier_db` 资源路径。空舞沿用极鬼人的刀身光效。磨刀与鬼人刀轨使用 Frontier 刀带模型及其图集。插件以 30 Hz 采样左右手挂点，按原版曲线计算每条刀带的 24 对顶点。刀带沿刀轴的长度分别取自当前装备的两件刀模，交给 GU 模型粒子绘制。极鬼人回避的残影发射点随猎人朝向前移 130 单位。

选中风格后由注册器写入 `savedata:/style_registry.ini`。可分别选择双剑和大剑风格。

```ini
[Weapons]
0 = 1
11 = 2
```
