# 极之型缺陷跟踪

2026-11-28 收录的玩家反馈及本轮离线排查结果。

| 编号 | 反馈与触发条件 | 处理结果 |
| --- | --- | --- |
| 01 | **太刀**持刀冲刺中，斩槽有余量时按特殊攻击键，无法发动解放连击。 | 普通冲刺、强弱两种冲刺蓄气都优先接解放。回放覆盖 GU 冲刺过滤掉特殊攻击键后的满斩槽输入。 |
| 02 | **持刀冲刺**中无法发动狩技。 | 六把极之型武器逐个检查三个狩技槽进入 GU 指令表。磁斩锤两种形态使用 GU 的三个方向快捷键回放起跑、续跑和刹停。 |
| 03 | **斩斧**属性解放过程中按 A 派生，会切回原版斩斧的属性解放。 | 原版地面攻击请求让给极之型控制器。回放检查属性解放突刺按 A 进入边境动作 169。 |
| 04 | **铳枪**「打火机」一直生效。 | 橙槽归零时立即清掉刀焰，发射和全弹结算重新检查点火状态。原版龙击炮冷却仍独立控制枪管发红。 |
| 05 | **斩斧**挨打后接翻滚，再按攻击，无法派生回避斩。 | 前滚可接受带方向的 X+A，前滚攻击中补齐的组合键也可替换已预输入的单键。回放覆盖受击后光剑前滚向左接袈裟斩。 |
| 06 | **斩斧**蓄力过程中光剑槽耗尽，角色卡在动作里。 | 光剑蓄力起手、原地或移动蓄力中耗空光剑槽后进入收剑变形。回放覆盖剑鬼计时耗尽时的原地蓄力。 |
| 07 | **极之型大剑**蓄力时，武器模型自带的特效和变形没有触发。 | 定位到 GU 大剑模型更新函数 30A8B0。原版只识别原生蓄力动作，现按极之型蓄力档位驱动装备模型的三个蓄力通道。 |
| 08 | **斩斧**发动剑鬼后再用能量装填，能量没有正常回复。 | 尚未复现反馈。执行 GU 的 11A08E0 和原生过帧判定，剑鬼期间的能量装填在第 56 帧回填斩击槽，基础回复依等级为 75／100／100，上限 100。 |
| 09 | **MHF-Z 受身**动作不生效。 | 共用受身判定保留下降接近地面时的 B 输入，GU 确认落地后发动。回放覆盖前后击飞、提前按键、耐力不足和致命受击。 |
| 10 | **太刀**解放连击挂到某些怪物部位时丢伤害。 | 追击遇到特殊受击变换或缺少关节矩阵时，以怪物根部保存实际命中点。回放覆盖普通关节和特殊编号 1010。反馈中的具体怪物和部位未知。 |
| 11 | **猎人名片**没有显示扩展装备模型。 | 自己的名片在模型加载完成后补绑定。新版快照在 GU 名片装备记录的保留字节中携带装备编号和等级，收到名片的一方可使用已安装的对应模型。 |

回放入口包括[公共动作](../plugins/mhgu-sdk-runtime/tests/verify_ground_recovery.py)、[狩技](../plugins/mhgu-sdk-runtime/tests/verify_weapon_arts.py)、[斩斧](../plugins/switch-axe-extreme/tests/verify_port.py)、[太刀](../plugins/long-sword-extreme/tests/verify_port.py)、[大剑](../plugins/great-sword-extreme/tests/verify_style.py)、[铳枪](../plugins/gunlance-extreme/tests/verify_port.py)和[扩展武器模型](../plugins/magnet-spike/tests/verify_magnet_spike.py)。
